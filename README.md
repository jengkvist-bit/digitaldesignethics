# digitaldesignethics.com

Webbplatsen för Digital Design Ethics, byggd med [Astro](https://astro.build) och publicerad på GitHub Pages.

- Texter: `src/content/sidor/*.md`
- Design: `src/styles/global.css`
- Bilder: `public/bilder/`

Varje gång något läggs in i `main` byggs sajten och publiceras automatiskt.
